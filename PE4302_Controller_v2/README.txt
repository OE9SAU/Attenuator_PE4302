PE4302 Controller v0.5 – by OE9SAU
Windows: Python 3 installieren, dann start_windows.bat starten.
Abhängigkeit: PySide6 (wird beim ersten Start installiert).
Alle Bedienelemente arbeiten nur im Simulationsmodus; keine USB-Anbindung.
Die Frequenzkennlinien sind illustrativ, keine Hersteller-Messdaten.
Layout optimiert für 1500 x 1010 Pixel, Windows-Skalierung 100%.

Version 0.6: Direkteingabe ueber Setzen oder Enter erzeugt ATT-Befehl im Simulationsprotokoll.
